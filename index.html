Petunjuk Setup Backend Google Drive & Spreadsheets

  1. Buat folder baru di Google Drive (misal RiverImpact_Cisadane_Uploads) dan salin ID folder dari URL.
  2. Buat Google Spreadsheet baru, buka menu Extensions > Apps Script.
  3. Ganti kode bawaan dengan backend di bawah ini, lalu isi DRIVE_FOLDER_ID dengan ID folder Google Drive Anda.
  4. Klik Deploy > New deployment, pilih jenis Web app.
  5. Set Execute as: Me dan akses sesuai kebijakan organisasi (untuk uji awal dapat Anyone). Deploy, izinkan akses Drive/Sheets, lalu salin URL berakhiran /exec.
